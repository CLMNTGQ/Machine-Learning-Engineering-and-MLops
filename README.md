# Machine Learning Engineering & MLOps

**[Read the course online](https://clmntgq.github.io/Machine-Learning-Engineering-and-MLops/course/)**

**[Open the presentation in your browser](https://clmntgq.github.io/Machine-Learning-Engineering-and-MLops/ml-engineering.html)**

A 24-hour, hands-on engineering course on turning a notebook model into a reproducible, testable, and observable ML service. A running industrial sensor example connects design decisions to deployment and operations.

## What you’ll learn

- Set an operating scope and track versions of data, code, experiments, and models.
- Test ML systems and build CI/CD/CT pipelines.
- Package and serve models in OCI containers, and practise controlled rollout and rollback.
- Monitor service and model behaviour, investigate drift and out-of-distribution inputs, and decide when to retrain.
- Design for CPU, latency, and resource constraints, with explicit fallback behaviour.

The labs use CPU-only tools and run with Podman or Docker. Basic Python, Git, and command-line skills are recommended.
